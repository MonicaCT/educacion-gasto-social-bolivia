Gasto educativo en el contexto regional

Mapas anuales de gasto educativo en América Latina, incluida Bolivia; datos y código R del estudio original.

Alcance e interpretación

Se conservan los mapas anuales, el libro SpatialEconometrics.xlsx y el script R original. El indicador del código es g_educacion. No se incorpora una atribución institucional de la base que el repositorio no documente. El script requiere un objeto cartográfico world que no viene definido ni suministrado: los mapas se pueden consultar, pero la reproducción completa necesita resolver esa dependencia.

Período: 1990–2020
Fuente declarada: Base SpatialEconometrics del proyecto

Procedencia y reproducción

Repositorio original

La migración conserva la evidencia publicada; no actualiza los datos ni vuelve a estimar resultados. Consulte el código y los documentos originales disponibles para conocer los requisitos de cada análisis.
