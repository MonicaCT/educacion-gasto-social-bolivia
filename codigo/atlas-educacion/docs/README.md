## Regla de lectura

Los indicadores del dashboard son principalmente **descriptivos**. Deben interpretarse dentro del territorio y filtros seleccionados. Cuando una medida es derivada —por ejemplo, índice de envejecimiento o dependencia demográfica— su fórmula está documentada explícitamente.
