# Assets

[← Volver al repositorio](../README.md)

Esta carpeta está reservada para recursos visuales o estáticos que el proyecto pueda necesitar en versiones futuras.

## Qué puede incluirse aquí

- logotipo o identidad visual propia del proyecto;
- imágenes optimizadas para la documentación;
- favicon;
- capturas oficiales del dashboard para el README;
- archivos CSS o JavaScript separados si el proyecto deja de ser autocontenido.

## Qué no debe incluirse

- copias duplicadas del dashboard;
- archivos temporales;
- bases de datos originales;
- credenciales o claves;
- materiales de terceros sin revisar sus condiciones de uso.

La versión inicial del dashboard permanece principalmente autocontenida en `index.html`, por lo que esta carpeta puede estar casi vacía.
